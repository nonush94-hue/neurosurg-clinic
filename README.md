# Neurosurg Exam

Bedside neurological examination form for neurosurgery (Italian UI). Fill in the findings during the visit, tap **Fine esame → Report**, and copy a ready-to-paste note for the clinical record.

- Templates: lumbar, cervical, cranial, complete
- Step-by-step exam guide and glossary
- Works offline and can be installed on iPad/iPhone (Share → Add to Home Screen)
- No server, no tracking: data stays in the browser of the device until "Nuovo paziente"

Part of the Neurosurg family: Neurosurg Predict, Neurosurg Learn, Neurosurg Exam.
